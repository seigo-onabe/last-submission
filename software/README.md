# Minesweeper software submission

C++17で実装したマインスイーパーソルバーです。盤面の数字制約から安全セルと地雷セルを
確定し、論理的に決められない場合は地雷確率が最も低いセルを選択します。

## 実行環境と評価入力

- 実行環境：paiza.IO
- 評価盤面：10000盤
- 入力方法：10000盤面のファイルを11分割して与え、各分割ファイルを個別に処理
- paiza.IO向けの入力：コマンドラインでファイル名が指定されない場合は、カレント
  ディレクトリの `board.txt` を入力ファイルとして読み込む

## ソルバーの構成

- 基本規則：残り地雷数が0の近傍は全安全、未確定セル数と等しい近傍は全地雷
- 全体地雷数：盤面全体の残り地雷数から安全セル・地雷セルを確定
- 部分集合規則：2つの数字制約の差分から追加の安全セル・地雷セルを確定
- 確率選択：制約を連結成分ごとに列挙し、地雷確率が最小のセルを選択
- 大規模・高密度な盤面では列挙ノード数を制限し、上限超過時は近似確率へ切替
- 複数盤面は最大2スレッドで並列処理

## 実装上の工夫

- 最大 `19 × 19` の盤面を固定長配列で管理
- 盤面ファイルを一括で読み込み、軽量なパーサで解析
- Union-Findによる制約グラフの成分分割
- 制約数の多い変数から列挙する順序付けと、残り地雷数による枝刈り
- 実行時間を1,750 msに制限し、入力順を保ったまま盤面結果を集計

## 出力項目

- 処理盤面数
- 開放した安全セル数と地雷数
- 合計スコア
- 実行時間

`--details` 指定時は、盤面名、解決可否、開放数、スコア、推測回数、厳密確率・近似確率を
使用した推測回数も出力します。
