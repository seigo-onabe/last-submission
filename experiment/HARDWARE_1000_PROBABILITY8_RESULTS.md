# 場合の数推論8回版 FPGA実機1000盤測定結果

## 概要

場合の数推論による確率選択を最大8回に制限したRTLをQuartus Prime Lite 24.1stdで
再コンパイルし、MU500実機上で`board_pack_1000_fpga.txt`の全1000盤を実行した。

FPGAへのSOF書き込み、Virtual JTAGによる盤面転送、結果回収はすべて正常に完了した。

## 変更した設定

`experiment/rtl/top/minesweeper_jtag_submission_local_top.v`を次の設定に変更した。

| パラメータ | 設定値 |
|---|---:|
| `MAX_PROBABILITY_GUESSES` | 8 |
| `BASE_PROBABILITY_GUESSES` | 8 |
| `ENABLE_SATURATING_HALF_SAFE_FEEDBACK` | 0（無効） |
| `ENABLE_ADAPTIVE_FEEDBACK` | 0（無効） |
| `ENABLE_LOW_SCORE_EDGE_RESCUE` | 1（有効） |
| `LOW_SCORE_RESCUE_SAFE_THRESHOLD` | 16 |

これにより、場合の数推論で求めた最小リスクセルを実際に開く確率選択は、各盤面につき
最大8回で終了する。低スコア時の辺中央救済など、それ以外の条件は維持した。

## 実行条件

| 項目 | 内容 |
|---|---|
| 実行環境 | MU500実機 |
| FPGA | Cyclone IV E `EP4CE30F23I7` |
| クロック | 20 MHz |
| 盤面数 | 1000盤 |
| 入力データ | `experiment/official/board_pack_1000_fpga.txt` |
| 通信 | USB-Blaster / Virtual JTAG |
| JTAGモード | fast |
| ソルバー | 決定論的ソルバー＋場合の数推論 |

## 集計結果

| 指標 | 合計 | 1盤平均 | 最小 | 最大 |
|---|---:|---:|---:|---:|
| サイクル数 | 76,802,797 | 76,802.797 | 1,208 | 1,251,180 |
| スコア | 892.9206 | 0.8929206 | -0.0637 | 1.0000 |
| 開いた安全セル数 | 99,848 | 99.848 | 8 | 312 |
| 開いた地雷数 | 1,214 | 1.214 | 0 | 8 |

サイクル数の中央値は28,364.5サイクルだった。20 MHz動作時、全盤面の合計
76,802,797サイクルは約3.840秒分のFPGA処理に相当する。

## 前回設定との比較

前回は通常8回に加えて、安全セルの半分を開くまで確率選択を継続する設定だった。

| 指標 | 前回設定 | 最大8回 | 差（8回版−前回） |
|---|---:|---:|---:|
| 合計サイクル数 | 81,110,615 | 76,802,797 | -4,307,818 |
| 平均サイクル数 | 81,110.615 | 76,802.797 | -4,307.818 |
| 平均スコア | 0.9038487 | 0.8929206 | -0.0109281 |
| 開いた安全セル合計 | 101,775 | 99,848 | -1,927 |
| 開いた地雷合計 | 1,233 | 1,214 | -19 |
| 完全解答数 | 862 | 858 | -4 |
| 途中停止数 | 138 | 142 | +4 |

最大8回に制限すると、合計サイクル数は約5.31%減少した。一方、平均スコアは
約0.01093低下し、完全解答数は4盤減少した。開いた地雷数は19セル減ったが、
開いた安全セル数も1,927セル減っている。

## ビルドと実機書き込み

Quartusフルコンパイルはエラー0件で成功した。20 MHzクロックに対する最悪setup slackは
7.073 ns、最悪hold slackは0.371 nsであり、指定クロックのタイミングを満たしている。

生成した8回版SOFは次のファイルである。

- `experiment/deliverables/minesweeper_probability8_mu500.sof`

Quartus Programmerによる実機書き込みもエラー0件・警告0件で成功した。

## 詳細結果

盤面ごとの測定結果は次のCSVに保存した。

- `experiment/hardware_1000_probability8.csv`

CSVには盤面ごとのサイクル数、スコア、開いた安全セル数、開いた地雷数、選択回数、
停止状態、JTAG再試行回数などが含まれている。

## スコア

各盤面のスコアは次の評価式に相当し、小数点以下4桁の固定小数としてFPGA内で計算される。

```text
スコア = 開いた安全セル数 / 全安全セル数
       - 開いた地雷数 / 全地雷数
```
